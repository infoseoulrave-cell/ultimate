📸 인스타그램에 올리는 방법

1. 각 카드 HTML을 브라우저에서 열기
2. 브라우저 창 크기를 1080×1080에 맞추기 (또는 개발자 도구에서 디바이스 크기 설정)
3. 스크린샷 또는 Cmd+Shift+4 (Mac) / Win+Shift+S (Windows)로 캡처
4. 인스타그램 피드에 업로드

💡 자동화: npm install puppeteer 후 스크립트로 일괄 PNG 변환 가능
